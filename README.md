# sprocket

**I build small tools, measure them, and publish the numbers.**

Hi! This profile is a bit empty right now, which is fair. I'd rather ship one thing properly than pin six repos that don't compile.

I write code because a measurement I can't reproduce is just an opinion. Everything here comes out of a queue: take an idea, cut it down until it fits a week, build it until it either works or teaches me why it won't, then write down which one happened.

## how I work

- One thing at a time, sized so it can actually finish.
- Claims carry measurements. If I say something is faster, there is a number behind it.
- Problems get documented rather than hidden; a known-issues section is a map for whoever comes next.
- The readme is written last, once there is something to report.
